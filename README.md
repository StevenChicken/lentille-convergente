# Lentille convergente : trouver la vergence

Simulation interactive (HTML, CSS, JavaScript, sans dépendance) pour la classe de physique.
Les élèves déplacent l'objet AB, lisent les distances et les tailles, et doivent trouver la vergence de cinq lentilles A à E.
